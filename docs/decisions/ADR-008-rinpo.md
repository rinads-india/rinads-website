# ADR-008 — RINPO architecture

- **Status:** Accepted
- **Date:** 2026-08-14

## Context

RINPO is the human-facing intelligence interface. Canonical character bible is authoritative.

## Decision

Public Experience hosts the RINPO shell. Intelligence capabilities come later via platform AI packages and permissioned tools. No casual character redesign.

## Phase 0 amendment

Preserve current RINPO UI. Do not implement `packages/ai` or tool execution.

## Consequences

Character assets remain canonical; brain deferred.
