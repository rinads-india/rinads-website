## 3. Honest scope statement

The MVP delivers a **complete, tested, tenant-scoped vertical slice for every area**, with deterministic logic in a pure package, additive RLS-protected schema, governed write paths, and truthful "not connected / no data" states. Where a real external system is required (Google/Meta/YouTube ads APIs, GitHub/Vercel tokens, carrier APIs, telephony, live LLM narration) the code ships the **provider-neutral adapter contract and fail-closed `not_connected` state**; it does not fabricate data. Staging, authenticated UAT, applying migrations to any Supabase project and promotion to production are founder-only operations and are listed as exact manual actions in the production-readiness report.
